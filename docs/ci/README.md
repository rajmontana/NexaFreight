# Deployment — Render (free) + Neon (free) · $0/month

**Decision (owner, 2026-08-26):** hosting switched from Hugging Face Spaces
(Docker gated on the owner account) to **Render free web service + Neon
Postgres**. HF_TOKEN / HF_SPACE no longer needed.

## One-time setup (~10 min)

### 1. Neon database (5 min)
1. https://neon.tech → sign up (free, no card)
2. **Create project** (default settings) → copy the **connection string**
   (`postgresql://user:pass@ep-xxx.neon.tech/neondb?sslmode=require`)

### 2. Delete the old HF deploy workflow (one push from your machine)
```bat
cd D:\smart_track
git pull
git rm .github\workflows\deploy.yml
git commit -m "ci: remove HF deploy workflow (switched to Render blueprint)"
git push
```

### 3. Render service (5 min)
1. https://render.com → sign up **with GitHub**
2. Dashboard → **New → Blueprint** → select `rajmontana/NexaFreight`
   → Render reads `render.yaml` and prompts for the missing values:
   - `DATABASE_URL` → paste the Neon string
   - `SEED_USER_PASSWORD` → your operator login password (min 8 chars)
   - `AISSTREAM_API_KEY`, `GROQ_API_KEY` → your keys
   - `CORS_ORIGINS` → `https://<service-name>.onrender.com,http://localhost:8000`
   - `JWT_SECRET` → auto-generated by Render
3. **Apply** → Render builds the Docker image and boots:
   migrations → data bootstrap (first boot ~2–4 min) → API live
4. Your app: `https://<service-name>.onrender.com` (HTTPS, any device)

### 4. Keep-alive (2 min, avoids 15-min idle sleep)
https://cron-job.org → free account → Create cron job → URL
`https://<service>.onrender.com/api/health` every 10 minutes.

## After first deploy — go live (staging-before-prod rule)

1. Verify: `/api/health` ok → login as `manager@nexafreight.com` → `/api/kpis`
   shows 65,752 shipments
2. Render dashboard → Environment → set `FEED_MODE=live` → Manual Deploy
   → AIS/OpenSky begin ingesting (check `/api/telemetry/live`)

## Ops notes
- Every push to `main` auto-deploys (Render watches the repo)
- Data persists in Neon; the container is stateless and rebuilds safely
- Rebuild data from source anytime: env `FORCE_INGEST=1` + Manual Deploy
- CI (lint+tests+secret scan) still runs on GitHub Actions for every push
