ML ENGINE

XGBoost regressor + exact TreeSHAP on every inference

Top feature importances (production model, GAIN-normalized)

  • 47-feature vector — order economics, geography, mode, weather, telemetry dwell, financial exposure.
  • 1,000-tree regressor served in-process via joblib; strict feature ordering enforced by the model's own feature_names_in_.
  • Native TreeSHAP contributions per inference — Σφᵢ + φ₀ = f(x) — so operators see why a shipment will be late, not just that it will.
  • Risk policy layer converts predicted days vs SLA into breach probability with per-mode floors (First Class base 87.4%).
  • MLOps feedback ledger captures every dispatcher decision for periodic re-training.
